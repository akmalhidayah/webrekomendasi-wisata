# Recommendation UI Assets

Folder asset:

- `public/assets/lottie/travel-intro.json`
- `public/assets/lottie/recommendation-loading.json`
- `public/assets/lottie/success-trophy.json`
- `public/assets/lottie/location-pin.json`
- `public/assets/illustrations/`

File JSON saat ini adalah placeholder valid agar aplikasi tidak error. Untuk mengganti dengan animasi asli, unduh asset Lottie dan timpa file JSON di lokasi yang sama.

Keyword pencarian di LottieFiles:

- travel
- map
- compass
- recommendation
- data analysis
- loading
- trophy
- success
- location pin

Jika animasi asli belum tersedia, UI tetap memakai fallback CSS, Bootstrap Icons, dan animasi ringan berbasis CSS.
